# HousePlan

Планировщик дома в браузере: участок и ландшафт, стены, окна и двери, этажи, лестницы, крыши и мебель. План и 3D-вид работают одновременно — изменили стену на плане, сразу видите результат в объёме.

Работает на компьютере, планшете и телефоне; ставится на главный экран как приложение и открывается без интернета.

Без сборки и без сервера: обычные ES-модули и Three.js, лежащий в репозитории. Выкладывается на GitHub Pages как есть.

**Демо:** `https://kutya001.github.io/HousePlan/` (после включения Pages, см. ниже)

## Возможности

**Участок и ландшафт**
- Граница участка по точкам или прямоугольником; готовые размеры 4–20 соток.
- Забор по границе (высота, цвет), площадь в сотках.
- Зоны: газон, плитка, гравий, асфальт, терраса, вода, грядки, цветник.
- Объекты: деревья (лиственные, хвойные, плодовые), кусты, клумбы, грядки, теплица, беседка, мангал, бассейн, колодец, детская площадка, автомобиль.

**Дом**
- Стены цепочкой с **примыканием при наведении**: концы прилипают к углам других стен (зелёный кружок) и к середине стены (ромб — Т-примыкание). Углы соединяются «на ус», перегородки аккуратно упираются в грань.
- Направляющие выравнивания по X/Y, углы 0/45/90°, сетка 5 см. Shift — строго 45°, Alt — без привязок.
- Точная длина с клавиатуры: начните стену, наберите `4,5` и Enter.
- **Коробка** одним жестом — 4 стены и пол. **Сразу 2 или 3 этажа** и крыша на выбор. Размер можно набрать: `8x10` Enter.
- Новая перегородка сама делит комнату на две; замкнутый контур стен сам становится комнатой.
- Комнаты кликом внутри стен, название, покрытие пола, чистая площадь по внутренним граням.
- Двери: одностворчатые, двустворчатые, раздвижные, гаражные ворота; сторона открывания и петли. Окна: одно-, двух-, трёхстворчатые, панорамные. Проёмы без дверей. Превью с расстояниями до углов, прилипание к центру стены.
- Этажи: высота, толщина перекрытия, высота цоколя. Новый этаж копирует наружные стены или всю планировку; этаж ниже виден пунктиром.
- Лестницы: прямая, Г-образная, П-образная, винтовая. Число ступеней считается от высоты этажа, в полу верхнего этажа вырезается проём.
- Крыши: двускатная, вальмовая, односкатная, плоская; уклон, свес. Кнопка «По контуру этажа» строит крышу по наружным стенам.
- 35 предметов мебели и сантехники и 14 объектов участка; мебель спинкой прижимается к ближайшей стене.

**Удобство**
- Режимы «План», «План и 3D», «3D». В 3D — орбита, вид сверху, **прогулка от первого лица** (WASD), разрез по этажу, выбор объектов кликом.
- Размерные линии как на чертеже, подписи комнат с площадью.
- Ручки: концы стен (соседние стены тянутся следом), поворот и размер мебели, вершины комнат и участка (тяните середину ребра — появится новая вершина).
- Стену можно тащить целиком — она двигается перпендикулярно себе, комнаты пересчитываются.
- Отмена/повтор на 120 шагов, копирование, дублирование, поворот, сдвиг стрелками.
- Пресеты: коробки 1 и 2 этажа с настраиваемыми размерами, дом 9×9, двухэтажный 10×12, Г-образный дом, баня 6×4, гараж 4×6 — с мебелью и благоустроенным участком.
- **Контекстное меню** (правая кнопка или долгое нажатие): «Дверь здесь», «Окно здесь», «Разделить стену здесь», поворот, копия, удаление.
- **Поиск команд** (Ctrl+K): инструменты, действия, этажи, пресеты и любой предмет каталога по названию.
- После удаления — уведомление с кнопкой «Отменить».
- Каталог помнит недавние предметы; у мебели, лестниц и крыш можно задать точные координаты.
- **Тёмная тема** (светлая / тёмная / как в системе), шаг привязки 1–25 см — в настройках (Ctrl+,).
- Автосохранение в браузере, экспорт/импорт проекта в JSON, картинки плана и 3D в PNG.
- Горячие клавиши работают в любой раскладке (W = Ц).

**Телефон и планшет**
- На телефоне: нижняя панель инструментов с группами (Стены, Проёмы, Объекты, Участок), шапка с выбором этажа и переключателем План/3D, всё остальное — в меню ☰.
- Свойства, каталог и этажи — в шторке снизу: тяните за ручку, чтобы развернуть на весь экран или закрыть.
- Касание выделяет объект, затем его можно тянуть — случайный сдвиг плана ничего не испортит. Палец по пустому месту двигает план, два пальца — масштаб.
- При рисовании точка ставится, когда отпускаете палец: видно превью и длину до того, как стена появится. Второй палец (масштаб) не сбрасывает начатую цепочку.
- Кнопки «Готово», «Убрать отрезок» и поле точной длины — прямо в панели инструмента.
- Панель действий с выделенным (Свойства, Копия, 90°, Удалить) появляется под пальцем.
- Крупные зоны нажатия (44 px), шрифт полей 16 px (iOS не увеличивает страницу), отступы под «чёлку» и жесты системы.
- 3D-прогулка с экранным джойстиком: джойстик — идти, палец по экрану — оглядеться.
- Планшет: инструменты слева, панель свойств выезжает справа. Горизонтальный телефон экономит высоту.

**Установка как приложение (PWA)**
- В Chrome на Android — меню ☰ → «Установить на телефон» (или пункт браузера «Добавить на главный экран»). В Safari на iPhone — «Поделиться» → «На экран Домой».
- После первого открытия приложение работает без интернета; онлайн всегда загружается свежая версия.

## Запуск

### GitHub Pages
1. Откройте репозиторий → **Settings** → **Pages**.
2. В **Build and deployment** выберите **Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через минуту приложение откроется по адресу `https://kutya001.github.io/HousePlan/`.

Файл `.nojekyll` уже в корне — GitHub отдаёт файлы без обработки Jekyll.

### Локально
Браузер не загружает ES-модули с диска (`file://`), нужен любой статический сервер:

```bash
cd HousePlan
python -m http.server 8000
# открыть http://localhost:8000
```

или `npx serve .`

**Во время рисования:** число + Enter — точная длина; Enter, двойной клик или правая кнопка — закончить; Backspace — убрать последнюю точку; Esc — отмена.

**На сенсорном экране:** касание — выбрать; палец по пустому месту — сдвиг; два пальца — масштаб; долгое нажатие — меню действий; при рисовании точка ставится при отпускании пальца.

## Архитектура

Никакого монолита и никакой сборки: каждый модуль отвечает за одну вещь, связи — через шину событий и хранилище.

**Поток данных.** Инструмент или кнопка вызывает `store.commit(fn)` → Store делает снимок для отмены, меняет проект и шлёт `project:changed` → 2D перерисовывается в ближайшем кадре, 3D пересобирается, панели обновляют значения, проект сохраняется в браузере. Состояние интерфейса (этаж, выделение) живёт в `AppState` и в историю не попадает.

**Раскладки.** `responsive.js` определяет телефон (до 760 px), планшет (до 1180 px) и ПК, плюс сенсорный ли ввод. CSS переключает раскладку медиазапросами, а JS — поведение: шторка или боковая панель, панель действий, крупные зоны попадания, фиксация точки при отпускании пальца.

**Темы.** Цвета интерфейса — CSS-переменные в `tokens.css` (`:root[data-theme='dark']`), цвета чертежа — объект `THEME` в `editor/render/theme.js`, который меняется на месте при смене темы.

**Единицы.** Все размеры — в метрах, ось Y плана направлена вниз. В 3D точка плана `(x, y)` становится `(x, высота, y)`.

### Формат проекта

```jsonc
{
  "version": 1,
  "name": "Мой дом",
  "foundation": 0.45,                         // цоколь, м
  "site":  { "boundary": [{"x":0,"y":0}, ...], "fence": { "enabled": true, "height": 1.8 } },
  "levels":   [{ "id": "lvl_…", "name": "1 этаж", "height": 2.8, "slab": 0.25 }],
  "walls":    [{ "id", "levelId", "x1","y1","x2","y2", "thickness", "height": null, "kind": "exterior|interior" }],
  "openings": [{ "id", "wallId", "kind": "door|window|arch", "style", "t", "width", "height", "sill", "flipSide", "flipHinge" }],
  "rooms":    [{ "id", "levelId", "name", "points": [...], "floor": "parquet|laminate|tile|…" }],
  "stairs":   [{ "id", "levelId", "shape": "straight|L|U|spiral", "x","y", "rotation", "width", "length", "flight" }],
  "items":    [{ "id", "levelId|site", "type", "x","y", "rotation", "w","d","h", "elevation", "color" }],
  "roofs":    [{ "id", "levelId", "type": "gable|hip|shed|flat", "x","y","w","d", "rotation", "pitch", "overhang" }],
  "zones":    [{ "id", "material", "points": [...] }]
}
```

`t` у проёма — расстояние от начала стены до центра проёма. Стены этажа по умолчанию высотой «этаж + перекрытие».

### Как расширять

- **Новый предмет мебели:** строка в `model/catalog.js`, значок плана в `editor/render/symbols2d.js`, модель в `view3d/builders/buildItems.js` (оба по ключу `type`; без них используется простой блок).
- **Новый инструмент:** класс-наследник `editor/tools/Tool.js` (обработчики указателя — у события есть флаг `e.touch`; `drawOverlay`; `options` и `actions()` для панели параметров; `shortHint` для подсказки на телефоне), регистрация в `editor/tools/index.js`, описание в `TOOL_META` (`ui/Toolbar.js`) и в группах панелей, клавиша в `app/shortcuts.js`.
- **Пункт контекстного меню:** `app/contextActions.js`.
- **После изменения файлов на GitHub Pages** service worker сам подтянет новую версию (стратегия «сначала сеть»); если меняете стратегию кэша — увеличьте номер в `CACHE` в `sw.js`.
- **Новый пресет:** функция в `model/presets.js` через помощник `B` (стены, комнаты, проёмы, мебель, крыша, участок) и запись в `HOUSE_PRESETS`.
- **Новое свойство в панели:** поле в `model/schemas.js` — форма построится сама.
